Sobre este Portafolio

Este espacio fue creado como una extensión del sitio web desarrollado en clase, con el propósito de presentar de forma visual y organizada los proyectos, avances y aprendizajes obtenidos durante la unidad de trabajo. La estructura sigue el mismo patrón semántico de las demás páginas del proyecto, utilizando etiquetas como section, article y figure.

Este portafolio se amplía de manera progresiva conforme se incorporan nuevas tecnologías y técnicas de maquetación al proyecto académico.

Proyectos y Bloques de Información

01 / Maquetación Estática

Construcción de la estructura base del proyecto utilizando etiquetas semánticas nativas de HTML5 para garantizar la accesibilidad, la legibilidad del código y el SEO básico del sitio web.

Etiquetas aplicadas: header, nav, main, section, article, aside, footer.

02 / Estilos y Modelo de Caja

Aplicación de propiedades de color, fondos, bordes y control preciso de los espacios internos (padding) y externos (margin) para transformar la visualización del documento HTML en una interfaz estilizada y coherente.

Propiedades clave: box-sizing, margin, padding, border-radius, background-color.

03 / Adaptación Responsiva

Implementación de consultas de medios (media queries) para asegurar que la interfaz se adapte correctamente en pantallas móviles con un ancho menor a 700px, reorganizando el menú, los formularios y los elementos multimedia.

Técnicas: @media, flex-direction, width: 100%, max-width.

04 / Navegación y Rutas Relativas

Organización del proyecto en carpetas y subcarpetas, utilizando rutas relativas correctas para enlazar páginas internas como buscar.html y contacto.html desde distintos niveles del árbol de archivos.

Conceptos: rutas relativas, atributo href, estructura de carpetas.

Entorno de Desarrollo

El desarrollo de este proyecto se llevó a cabo utilizando Visual Studio Code como editor principal, Git para el control de versiones y GitHub como repositorio remoto de acceso público.

Preguntas y Reflexiones del Proceso

¿Por qué es importante el HTML semántico?

Porque permite que navegadores, lectores de pantalla y motores de búsqueda comprendan la estructura del contenido, mejorando la accesibilidad y el SEO.

¿Qué fue lo más desafiante al aplicar CSS?

Comprender el modelo de caja y el comportamiento de box-sizing: border-box fue el reto principal, especialmente al construir formularios que debían verse correctamente tanto en escritorio como en dispositivos móviles.

¿Por qué se usó el enfoque Desktop-First en lugar de Mobile-First?

Porque el proyecto inició desde el diseño en pantalla grande para luego adaptarlo con media queries. En versiones futuras se planea migrar a un enfoque Mobile-First para optimizar la experiencia desde el inicio.
